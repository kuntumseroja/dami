Run it — the steps

Set your API key once

Edit .env line 3:

ANTHROPIC_API_KEY=sk-ant-<your-key>

Start the platform once

Then check localhost:8010/health → {"status":"ok"}.

docker compose up -d

Load the demo data once

Generates the PDFs, then creates 3 cases + ingests files. Copy the PTPN III case_id from the output.

backend/.venv/bin/python scripts/generate_samples.py backend/.venv/bin/python scripts/seed.py

Open the app → NOTA Drafting

Go to localhost:3010, then click NOTA Drafting in the left menu.

Fill the form & generate

Paste the case_id, (files already ingested by seed), optionally add instructions, then click Generate first draft. ~40 s.
