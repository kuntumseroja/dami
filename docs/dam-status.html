What works today

Delivered capabilities

A reviewer can take an SOE submission package from intake to a grounded draft NOTA, with deterministic routing, cross-document consistency, and a complete audit trail.

📄 Document understanding

Native PDF/DOCX extraction with native→Granite-Docling→Tesseract OCR escalation for scanned packages. OneDrive/SharePoint ingest via Microsoft Graph.

🔎 Grounded RAG

Structure-aware chunking + hybrid dense/sparse retrieval with reranking. Bilingual (Bahasa Indonesia + English).

✍️ NOTA drafting

Descriptive 80% generated & 100% source-cited; judgment sections reserved for humans; coverage metric + insufficient-source flags.

⚖️ SOP routing

Deterministic rule engine selects the SOP, approval level (CEO / Dewan Pengawas / Presiden RI), and risk tier. The AI explains; it never overrides.

🔁 Consistency checker

Cross-document audit of the artefact set vs the master submission — flags conflicting figures, dates, and stale references.

🗂️ Lifecycle & cover sheet

PRD 7-stage workflow with human checkpoints; auto-reconciled cover-sheet checklist whose required collateral varies by SOP.

🧠 Multi-model router

Cost-tiered Claude mix (Haiku→Sonnet→Opus) + self-host pool (Qwen3, DeepSeek-R1, Mistral, Gemma) per task role.

🛡️ Audit & explainability

Every AI call, fired rule, and transition recorded append-only; latency doubles as the perf record; full provenance per case.

🖥️ Carbon UI

IBM Carbon dashboard: active processes, needs-attention, document preview, lock/remove, per-draft SLA + coverage.

Engineering quality

Built to be trusted

Rules decide, AI explains

Approvals, risk tiers, and SOP selection are deterministic and reproducible. The model writes the explanation, never the verdict.

Provider-portable

Every external dependency sits behind a port. Claude today; watsonx / AWS / Databricks feasible via config + adapter swap — no core rework.

Lean by default

OCR and self-host backends are optional, lazily imported extras. The default image stays small; heavy capability is opt-in per deployment.

Measured, not asserted

Golden-set retrieval eval gates CI; latency SLA + coverage tracked from the audit trail; 54 backend tests.

Auditable by construction

Append-only trail of every AI call, fired rule, sign-off, and document removal — full provenance per case.

Human-in-the-loop

Judgment and recommendation sections are never machine-filled; SOE submissions are immutable; sign-off identity is authenticated.
